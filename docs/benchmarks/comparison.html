测量 npm 发布物中的 Node CLI 和 Rust 二进制，对照 build123d 0.11.1。每件每端单独预热一次，再交替执行五轮；用时取中位数，内存取五次 cgroup 峰值最大值。新进程含导入、验证和 STEP 导出，不含安装、容器启动、渲染或 agent 推理。常驻 Python 能摊薄导入成本；歧管的纯几何阶段 build123d 更快。
