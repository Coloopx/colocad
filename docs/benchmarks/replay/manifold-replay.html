交付同一块歧管，要等多久？

本次实录里，colocad 在 193 ms 交付 STEP，build123d 用了 2,050 ms。交付速度比为 10.6×，峰值内存占对方的 8.7%。

这段动画测了什么？

Linux arm64，1 vCPU，512 MiB，使用 npm 包 colocad 0.1.0-alpha.2 与 build123d 0.11.1。两端按同一组参数独立建模，预热后各取第一个新进程。两次调用依次运行，画面将启动时刻对齐，计时包含进程启动、导入、几何构建、验证及写出 STEP。曲线使用约 20 ms 间隔采集的 cgroup memory.current，峰值来自 memory.peak。内存计入了容器中的采样器与被测进程。成品图在计时结束后用同一相机从各自的 STEP 渲染。

片尾另列已有五轮基准，交付时间取五次中位数，内存取五次峰值的最高值。这里展示的是单件歧管。
